## What Is This?

A **systematic, evidence-based OSINT investigation** into documented connections between celebrity breakdowns, Jesuit educational networks, spiritual healers, performance artists, political figures, and ancient ritual practices.

> "Truth is stranger than fiction because fiction has to make sense."

This repo separates **verified facts** from **speculative claims** using multi-source cross-referencing via [Exa AI](https://exa.ai), GitHub API, and direct article fetching.

## Methodology

| Step | Tool | Purpose |
|------|------|---------|
| 1 | **Exa AI Search API** | Deep semantic search across 25+ verified news domains |
| 2 | **GitHub Search API** | Find related repos, datasets, and code |
| 3 | **Direct Article Fetch** | Pull full text from AP, Reuters, NBC, Vice, Hollywood Reporter |
| 4 | **Cross-Reference Engine** | Score claims by source tier (S-tier = AP/Reuters/BBC) |
| 5 | **Disturbing Score Algorithm** | Rank findings by keyword density |
